# 단일 페이지 구조 정리 및 검증

다음 두 단계를 반드시 순서대로 수행한다.

## 1단계: 구조 정리

`organize-single-page-code` 스킬의 지침을 적용한다.

* 파일을 분리하지 않는다.
* 공통 선언을 최상단의 `공통기능` 블록에 모은다.
* 나머지 코드를 업무 기능 단위로 구분한다.
* 필요한 레이어 주석만 추가한다.
* 동작, API, 식별자를 변경하지 않는다.

1단계 완료 후 바로 작업 완료로 보고하지 않는다.

## 2단계: 검증

`verify-single-page-organization` 스킬의 지침을 적용한다.

* 전체 diff를 검토한다.
* 의미 변경 여부를 확인한다.
* 포맷 검사를 실행한다.
* 타입 검사를 실행한다.
* 검사 후 diff를 다시 확인한다.

## 완료 조건

다음 항목을 모두 보고해야 작업이 완료된다.

1. 생성한 기능 블록
2. 코드 동작 보존 여부와 판단 근거
3. 실행한 포맷 검사 명령 및 결과
4. 실행한 타입 검사 명령 및 결과
5. 변경된 파일 목록
6. 잔여 위험 또는 실행하지 못한 검사

검사를 실행하지 못했으면 성공으로 간주하지 않는다. 실행하지 못한 이유와 미검증 범위를 명시한다.
